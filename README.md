# EcoRobot - Sustainable Autonomous Navigation
(EcoRobot - Navegação Autônoma Sustentável)

## 🌿 About the Project (Sobre o Projeto)
English: This project focuses on developing a mobile robot capable of identifying and collecting waste in real-time. By using AI-driven object detection, the goal is to optimize the recycling process and maintain cleaner environments with minimal human intervention.
(Português): Este projeto foca no desenvolvimento de um robô móvel capaz de identificar e coletar resíduos em tempo real. Ao utilizar detecção de objetos via IA, o objetivo é otimizar o processo de reciclagem e manter ambientes mais limpos com intervenção humana mínima.

## 🛠️ Key Features (Principais Funcionalidades)

Object Detection (Detecção de Objetos): Real-time identification of waste using YOLO models. (Identificação de resíduos em tempo real usando modelos YOLO.)

Autonomous Mapping (Mapeamento Autônomo): Environment navigation using SLAM technology. (Navegação no ambiente usando tecnologia SLAM.)

Sustainability Driven (Foco em Sustentabilidade): Designed to improve waste management efficiency. (Projetado para melhorar a eficiência da gestão de resíduos.)

## 💻 Tech Stack (Tecnologias Utilizadas)

Languages (Linguagens): Python, C.

AI/Vision (IA/Visão): YOLOv8, OpenCV.

Hardware (Hardware): Microcontrollers and sensors integration. (Integração de microcontroladores e sensores.)
